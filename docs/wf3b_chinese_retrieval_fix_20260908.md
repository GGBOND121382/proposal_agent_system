## 中文筛选修复

根因属实：`research_quality.concept_tokens()` 原先只提取拉丁词。四条中文查询的 `query_tokens` 全为空，同一研究问题下其他英文查询产生的英文锚点还会阻止中文网页通过。

本次修改：

- 使用连续汉字的重叠二元组，无需增加第三方分词依赖；孤立单字可被分词，但不用于相关性计分。
- 排除“系统、论文、研究”等中文通用词；中文查询使用适用的中文锚点，英文锚点不再否决中文或中英混合查询中的中文证据。
- 中文至少匹配三个有效 token，且匹配比例达到 55% 才能成为 SUPPORTING，70% 才能成为 DIRECT。避免长词拆出的多个二元组、少量共享单字制造虚假覆盖。
- 排序的 query alignment 同步加入中文 token；浏览器补查判断复用同一相关性评估。
- 中文实体别名支持无空格句内匹配；拉丁实体仍防止 DASH 与 dashboard 混淆。
